## ১. শুরু: প্রজেক্টের ধারণা (১৪ অক্টোবর)
- মালিক আগে নিজের ল্যাপটপে "টমি" নামে একটা ভয়েস অ্যাসিস্ট্যান্ট বানিয়েছিলেন, যেটা লোকাল OmniRoute (নিজের লগইন) দিয়ে চলত এবং বাংলা ভালো বুঝত না।
- লক্ষ্য: Instagram-এর "Myra AI"-এর মতো অ্যাসিস্ট্যান্ট — বাংলা ভয়েসে PC আর ফোন কন্ট্রোল, মিষ্টি মেয়েলি কণ্ঠ — এবং গ্রাহকদের কাছে বিক্রি।
- সিদ্ধান্ত: পুরনোটা না বদলে নতুন করে বানানো।
- Myra AI কীভাবে বানানো তার অফিসিয়াল তথ্য পাওয়া যায়নি; সাধারণত Python + রিয়েলটাইম ভয়েস API (Gemini Live / OpenAI Realtime)।

## ২. মডেল ও খরচ
- তুলনা: Gemini Live (সস্তা, দ্রুত) বনাম OpenAI Realtime (দামি)। GPT-Live-1 বেঞ্চমার্কে একটু ভালো কিন্তু দামি এবং তখন ডেভেলপার API ছিল না।
- **বেছে নেওয়া মডেল: Gemini 3.8 Live (`gemini-3.8-live`)** — সবচেয়ে কম latency, ৯৭ ভাষা, অডিও ইনপুট ~$0.005/মিনিট, আউটপুট ~$0.018/মিনিট।
- Gemini 3.1 Flash Live পুরনো (legacy) — ব্যবহার নয়।
- OmniRoute: ফ্রি ওপেন-সোর্স গেটওয়ে; ফ্রি টিয়ার দিয়ে বিক্রি করলে সার্ভিস খারাপ ও নিয়মের ঝুঁকি। ব্যক্তিগত লগইন গ্রাহকদের সাথে শেয়ার করা যাবে না।
- LiveKit আলোচনা হয়েছে: ভালো ফ্রেমওয়ার্ক, কিন্তু এখন দরকার নেই; অ্যাপ সরাসরি Gemini Live-এ যুক্ত হবে (সস্তা ও দ্রুত)।

## ৩. বিক্রির জন্য আর্কিটেকচার
- গ্রাহক PC-তে শুধু Setup.exe, ফোনে শুধু APK — বাকি কিছু করতে হবে না।
- টমির "মগজ" মালিকের সার্ভারে; আসল API কী শুধু সার্ভারে; অ্যাপ অস্থায়ী (একবার-ব্যবহারযোগ্য) টোকেন নিয়ে সরাসরি Gemini-তে যায়।
- খরচ কমানো: ওয়েক ওয়ার্ড ও VAD লোকালি; সাধারণ কমান্ড (ফোল্ডার খোলা, ভলিউম) লোকালি API ছাড়া; ছোট উত্তর; রিসার্চ সস্তা টেক্সট মডেলে আর ফল স্ক্রিনে লেখা হিসেবে; সেশন রিসেট; প্রতি প্ল্যানে AI-মিনিট লিমিট।

## ৫. ফিচার সিদ্ধান্ত
- **ডিজাইন (Myra ভিডিও দেখে):** "Hello, <নাম>", চরিত্রের ছবি, ঘুরন্ত ক্রিস্টাল/অর্ব, ওয়েভফর্ম, স্ক্রিনের কিনারায় রং বদলানো নিয়ন আলো, Home/Chat/মাইক/Triggers/Settings, ভাসমান অর্ব।
- **কাজের ধরন:** কোনো কাজে তথ্য কম থাকলে ছোট প্রশ্ন ("কাকে মেসেজ পাঠাবো?"); পাঠানো/কল/ডিলিটের আগে নিশ্চিত হওয়া।
- **থিম:** ৫–৬টা প্রাপ্তবয়স্ক অ্যানিমে চরিত্র (নিজস্ব ছবি, কপি নয়) — crimson, violet, aqua, sakura, gold, emerald (শেষ দুটো ছেলে চরিত্র, প্রস্তাবিত)।

## ৬. যা বানানো হয়েছে (১৫ অক্টোবর)
- **সার্ভার (`server/`, Python FastAPI):** লগইন, লাইসেন্স, ডিভাইস লিমিট, নাম/থিম/কণ্ঠ/ভাষা, ওয়েক ওয়ার্ড টেমপ্লেট, এনক্রিপ্টেড মেমোরি, ট্রিগার, AI-মিনিট হিসাব, Gemini Live টোকেন, রিসার্চ, অ্যাডমিন। ১৭টা টেস্ট পাস।
- **অ্যাপ (`app/`, Flutter — একই কোডে Android + Windows):** লগইন/রেজিস্টার, সার্ভারের ঠিকানা বসানোর ঘর, হোম অ্যানিমেশন, ৬ থিম, ৫ কণ্ঠ, নাম বদল, ৩ ভাষা, মেমোরি পাতা, লাইসেন্স চালু।
- **অটো-বিল্ড:** GitHub রিপো `chion21/tommy`; প্রতি push-এ GitHub Actions APK (arm64, ~১৭ MB) আর TommySetup.exe (~১০ MB) বানিয়ে Releases → "latest"-এ রাখে। প্রথম বিল্ড প্রথম চেষ্টাতেই সফল।

## ৭. সার্ভার কোথায় চলবে
- Oracle Cloud Always Free চেষ্টা — কার্ড যাচাইয়ের পাতা মোবাইলে পাওয়া যায়নি; বাদ।
- **এখন: মালিকের ল্যাপটপে** — `server\start_server.bat` ডাবল-ক্লিক → প্রথমবার Gemini কী চায়, গোপন কী নিজে বানায়, Cloudflare ফ্রি টানেল দিয়ে `https://….trycloudflare.com` ঠিকানা দেয় (প্রতি রিস্টার্টে বদলায়)। অ্যাপের লগইন স্ক্রিন/Settings-এ এই ঠিকানা বসাতে হয়।
- ডোমেইন এখন লাগবে না; পরে DuckDNS (ফ্রি) বা কেনা ডোমেইন।
- বিক্রির আগে: Hetzner (Singapore, ~$৫–৮/মাস) বা DigitalOcean/Vultr; `server/setup_server.sh` দিয়ে এক কমান্ডে চালু।
